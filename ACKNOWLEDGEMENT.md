## 🛠️ Open Source & Technology Acknowledgements

DarshanAI is powered by top-tier open-source tools and frameworks:

1. **FastAPI & Starlette** — For the high-throughput asynchronous backend web framework.
2. **React 18 & Vite** — For the responsive, component-driven client command center and lightning-fast HMR build tooling.
3. **Ultralytics YOLOv8 & OpenCV** — For real-time computer vision inference, devotee bounding box detection, and video stream processing.
4. **Scikit-Learn** — For the ensemble machine learning algorithms (Random Forest, Gradient Boosting, Isolation Forest).
5. **Leaflet & React-Leaflet** — For interactive GIS geographic zone mapping and real-time density rendering.
6. **SQLAlchemy** — For enterprise database ORM modeling, connection pooling, and multi-tenant data isolation.
7. **Google Antigravity** — For pair-programming agentic workflows, collaborative team sync protocols, and continuous integration.
